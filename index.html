Блок для вставки (только ники с данными)
Блок охватывает только тех ников из шаблона, у которых есть данные в отчёте. Ники, которых нет в отчёте, и строки-разделители внутри этого диапазона — пустые строки, чтобы позиции совпали. Выдели ячейку в левом верхнем углу блока и нажми Ctrl+V.
Загрузи Excel-шаблон с никами и датами. После загрузки текстового отчёта нажми «Построить блок для вставки» — получишь блок только для ников с данными. Скопируй и вставь с указанной ячейки.
